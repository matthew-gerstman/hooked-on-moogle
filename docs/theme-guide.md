# Hooked on Moogle: Square Enix Theme Guide

## Visual Identity

This guide defines the visual language for "Hooked on Moogle," blending Final Fantasy/Chrono Trigger aesthetics with child-friendly educational design.

---

## Moogle Character Design

### Core Visual Elements

**Body:**
- Round, fluffy white body (like a plush toy)
- Soft, approachable proportions
- Small stubby limbs

**Signature Features:**
- **Pom-pom antenna:** Red bobble on a thin stalk from the head
- **Wings:** Small, bat-like purple/red wings (too small to realistically fly)
- **Ears:** Cat-like or rabbit-like pointed ears
- **Face:** Simple dot eyes, small nose, gentle expression

**Color Palette:**
| Element | Color | Hex |
|---------|-------|-----|
| Body | Cream White | #FFF8F0 |
| Pom-pom | Cherry Red | #E63946 |
| Wings | Soft Purple | #9B5DE5 |
| Nose | Pink | #FFB4A2 |
| Outline | Warm Gray | #6B705C |
| Accent | Gold (Gil) | #FFD700 |

### Character Variations for Worksheets

**Mog (Main Guide):**
- Friendly, encouraging expression
- Often pointing or gesturing
- Wears a small red scarf (optional)

**Kupo (Helper):**
- Slightly smaller than Mog
- More playful poses
- Often shown with speech bubble saying "Kupo!"

**Letter Moogles:**
- Each letter gets a moogle holding/wearing/interacting with that letter
- M-oogle holds the letter M
- Consistent style, different poses

## Typography

### Primary Font (Letters/Learning)
- **Style:** Bold, rounded sans-serif
- **Characteristics:** Child-friendly, highly legible
- **Recommended:** Nunito Bold, Quicksand Bold, or similar
- **Size:** Minimum 48pt for target letters, 24pt for instructions

### Secondary Font (Titles/Headers)
- **Style:** Playful but readable
- **Characteristics:** Slightly whimsical, evokes RPG feel
- **Recommended:** Fredoka One or similar rounded display font

### Accent Font (Speech Bubbles)
- **Style:** Hand-drawn feel
- **Use:** "Kupo!" exclamations, moogle dialogue

## Illustration Style Guidelines

### Overall Aesthetic
- **Clean and simple** - not overly detailed
- **Rounded shapes** - soft, child-friendly
- **Flat colors with subtle shading** - easy to print
- **Consistent line weight** - 3-4px outlines
- **Whimsical but not chaotic** - organized compositions

### Do's ✓
- Keep moogles cute and approachable
- Use bright, saturated colors
- Include visual cues (arrows, dotted lines)
- Make interactive elements obvious
- Leave plenty of white space

### Don'ts ✗
- No scary monsters or battle scenes
- Avoid tiny details that won't print well
- Don't overcrowd pages
- No complex backgrounds that distract
- Avoid dark or muted color schemes

## Print Specifications

- **Page Size:** US Letter (8.5" x 11")
- **Orientation:** Portrait
- **Margins:** 0.5" minimum
- **Color Mode:** CMYK for print, RGB for screen
- **Resolution:** 300 DPI minimum
- **Bleed:** 0.125" if full-bleed backgrounds
