# Hooked on Moogle 🎈

A Final Fantasy/Square Enix themed phonics workbook for children ages 3-4, inspired by Hooked on Phonics methodology.

## What's Inside

- **10+ worksheet pages** teaching letter recognition and beginning sounds
- **Whimsical moogle illustrations** to engage young learners
- **Research-backed pedagogy** for pre-readers

## Project Structure

```
├── docs/           # Methodology and theme guides
├── assets/         # Moogle illustrations
├── src/            # HTML worksheet source
└── output/         # Generated PDF
```

## Methodology

See `docs/methodology.md` for the full pedagogical approach.

## Theme

Inspired by Final Fantasy moogles with their signature:
- Fluffy white fur
- Red pom-pom antenna
- Tiny wings
- "Kupo!" catchphrase

*Learning to read is an adventure, kupo!* 🎈
